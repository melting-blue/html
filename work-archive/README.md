# Work Archive

소담 개인 업무 기록용 웹앱.

## 화면
- 주간: 월~금 업무를 엑셀처럼 한 화면에서 확인
- 월간: 날짜별 프로젝트/업무량 빠르게 확인
- Projects: 프로젝트별 타임라인
- Search: 업무 원문 검색
- Data: TXT/MD 가져오기, JSON/CSV 백업

## 기록 원칙
- 업무 원문은 축약하지 않음
- `완료 / 진행 / 예정 / 막힘` 상태 필터는 사용하지 않음
- 과거 보고의 상태 제목은 가져오기 시 분류용 데이터로 저장하지 않음
- 프로젝트/유형/협업자만 검색용 메타데이터로 자동 추정

## 온라인 저장
`config.js`에 Supabase Project URL과 Publishable(Anon) key를 넣고 `supabase.sql`을 실행하면 온라인 동기화가 활성화됩니다.

인증은 회원가입/비밀번호 UI 대신 이메일 매직링크만 사용합니다. 한 번 인증한 브라우저는 세션이 유지됩니다.

> 업무 원본 TXT/MD는 공개 GitHub 저장소에 커밋하지 마세요. 앱의 Data 화면에서 직접 가져오면 DB에만 저장됩니다.
